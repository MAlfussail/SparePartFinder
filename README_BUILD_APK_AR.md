# تطبيق مطابق قطع الغيار بالذكاء الاصطناعي (Spare Parts AI Matcher v1.1)

يحتوي هذا المجلد على **الكود البرمجي الكامل لتطبيق الأندرويد (Flutter)** الجاهز لتحويله إلى ملف `.apk` وتثبيته على أي هاتف أندرويد.

## الجديد في خوارزمية الذكاء الاصطناعي المحلية (مقاومة زوايا التصوير وتغيرات الإضاءة)
1. **موازنة الإضاءة والظلال تلقائياً (Gray-World + Block Illumination Leveling + Z-Score):**
   - يعالج الصور الملتقطة في إضاءة ورشة خافتة أو تحت فلاش قوي أو بوجود ظلال جانبية قبل استخراج السمات.
2. **تحديد مركز ثقل القطعة والحلقات القطبية الدائرية (360° Rotation-Invariant Polar Rings):**
   - يحسب البصمة الهندسية حول المركز الفعلي للقطعة في حلقات دائرية وزوايا حواف نسبية للشعاع المركزي وطيف فورييه الدوراني، مما يجعل التطابق ثابتاً حتى لو التقطت الصورة بزاوية مائلة أو مقلوبة.
3. **بنك المحاذاة متعدد الزوايا (Multi-Angle Pose Bank):**
   - يختبر تطابق القطعة عبر زوايا الدوران القياسية (`0°, ±18°, ±35°, ±90°, 180°`) لاختيار أعلى تطابق هندسي.
4. **عزل اللون عن الإضاءة (HSV & RG Chromaticity):**
   - يفصل مركبة اللون والتشبع عن شدة السطوع (`V`) لضمان عدم تأثر لون القطعة بظروف الإضاءة.
